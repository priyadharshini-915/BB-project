About Our System

The Blood Bank Management System is a web application that helps manage blood donors, track blood stock, and handle blood requests efficiently. It connects donors with patients who are in urgent need of blood.

  • ✓ Register and manage donors
  • ✓ Check real-time blood availability
  • ✓ Submit blood requests
  • ✓ Admin can manage donors, stock and requests
